Bilibili CDN Filter v4.2.0

过滤 mcdn.bilivideo.cn、edge.mountaintoys.cn、szbdyd.com；清理播放器返回的
PCDN 备选地址，并在主地址命中时提升可用的 bilivideo.com 地址。扩展图标可查看
最近记录，日志会去掉查询参数并合并连续重复项。

安装：打开 chrome://extensions/ 或 edge://extensions/，开启开发者模式，选择
“加载已解压(未打包)的扩展程序”，加载本文件夹，然后刷新已打开的 Bilibili 页面。

本扩展只作用于浏览器中的 Bilibili 页面，不修改系统代理、DNS 或 Mihomo。
如果接口没有提供其他可用线路，过滤后可能需要刷新页面或切换清晰度。
